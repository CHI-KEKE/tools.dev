判斷時應該以 Event ID + Level + EventData 裡的 ResultCode 為主，不能單獨看到 Opcode 2 就判定失敗。

你的兩筆可以這樣比較：

Event	Level	意義
101	2 (Error)	Task 啟動失敗
102	4 (Information)	Task 執行完成

而 Opcode 2 在這筆 Event 102 的語境下，可以理解成 完成/結束階段，不是 ERROR_FILE_NOT_FOUND (2) 那個 Windows Error Code。

簡單記：

EventID = 發生什麼事；Level = 嚴重程度；Opcode = 事件處於哪種操作；ResultCode = 執行結果碼。

所以你前面那個 2147943731 才是真正需要解讀的 ResultCode。


對應的 Event ID 201（Action completed），那筆通常才會包含 ResultCode。
