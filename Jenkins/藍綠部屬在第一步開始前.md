意思是 Jenkins 先取得這次要執行的 JenkinsfileBlueGreenDeployWithASG，並載入公司內部的 Jenkins shared library。

Could not find 1.0.71 in remote references.
Pulling heads to local for deep search...
Selected match: feature/VSTS272866...

意思是它原本想找 1.0.71 這個 reference，但遠端 references 沒直接找到，所以 Jenkins 做更深層搜尋，最後找到對應 commit，並 checkout 到：

feature/VSTS272866_Support_release_to_master_and_develop

這不一定是錯，但值得注意：它沒有直接抓到名為 1.0.71 的 tag/branch，而是找到某個符合的 commit。

2. 開始 Blue Green Deployment

這段：

[Pipeline] { (Blue Green Deployment)
[Pipeline] { (Copy Artifact)

Blue/Green Deployment 通常是：

blue 機器目前服務中
green 機器準備新版

先部署其中一組
檢查正常
再切流量

從 log 看到這次的兩台 instance 是：

SG-HK-Loyalty11 DeployGroup: blue
SG-HK-Loyalty12 DeployGroup: green

意思是 Jenkins 把 nineyi.loyaltypoint 專案的 master 分支拉下來，版本是：

6fd21f5d0865756ca263ae1a61f933160a699ca8
