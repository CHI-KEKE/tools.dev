##  過濾邏輯

```csharp
.Where(item => !IsExcludedPath(item.Path))                // 排除 /AutoGenerated/、/i18n/
.Where(item => IsSupportedFile(item.FileName))            // 只保留 .cs 檔案
.Where(item => ContainsAddedLines(item.Section))          // 必須有 + 開頭的行
.Where(item => !IsAutoGeneratedContent(item.Section))     // 排除 <auto-generated> 標記
.Select(RemoveDeletedLines)                                // 移除 - 開頭的行
```
