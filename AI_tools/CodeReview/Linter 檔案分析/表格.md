


| 規則 | 處理模式 | 餵給 AI 的內容 | 內容來源 |
|---|---|---|---|
| GitHubAiAssistantRuleBase | 逐檔案 | 檔案 Metadata + Patch (Diff) | GitHub API 的 files 端點 |
| AiAssistantCodeMentorProDifyRule | 逐檔案 | 完整 Diff 區塊 | Bitbucket Diff API |
| AiAssistantDatabaseRule | 逐檔案 | 完整檔案內容 | Bitbucket Raw File API |
| AiAssistantSplitContentRule | 一次性 | 完整 PR Diff | Bitbucket Diff API |

| 特性 | GitHubAiAssistantRuleBase | GitLabAiAssistantRuleBase |
|---|---|---|
| 資料來源 | GetGitHubPullRequest() + GetGitHubDiffResponse() | GetGitLabDiffResponse() |
| 回傳結構 | 分離的 PR 資訊 + 檔案清單 | 整合的 Response（包含 Title, Description, Changes） |
| 檔案物件 | GitHubPullRequestFile (包含 Filename, Patch, Status) | Change (包含 NewPath, OldPath, Diff) |
| 內容格式 | JSON 格式 (JToken.ToString()) | Markdown 格式（手動組裝） |
| 刪除行處理 | 保留在 Patch 中 | 主動過濾移除 (if (diffLine.StartsWith("-")) continue;) |
| 評論位置 | 檔案級 (LineFrom = -1) | 檔案級 (LineFrom = -1) |
| API 呼叫 | 每個檔案 1 次 | 每個檔案 1 次 |
