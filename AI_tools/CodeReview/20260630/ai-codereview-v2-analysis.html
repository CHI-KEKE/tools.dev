Gap 分析 — V2 目前狀態
今日補齊項目 + 仍待處理項目
✅ 今日補齊

RemoveDeletedLines

送 Dify 前移除 - 行，避免 AI 針對已刪除的程式碼提出意見，同時節省 token。

✅ 今日補齊

HasAddedLines guard

確認 diff 含新增行才呼叫 Dify；若 PR 只有刪除沒有新增，直接略過不送 AI。

✅ 今日補齊

IsAutoGeneratedContent guard

偵測 diff 前 20 行是否含 <auto-generated> 標記，自動生成的程式碼不做 AI Review。

🔴 高優先 待處理

Inline Comments 接入

PostReviewCommentAsync 已實作（含 filePath / startLine / endLine），但 CodeReviewService 尚未 wire 進去。目前只有 PR 層級留言，無法指向特定程式碼行。

🟡 中優先 待確認

Priority 分組留言

Linter 依 High / Medium / Low 各發一則留言，視覺上清楚。V2 全部聚合進同一則 <details>，長 PR 時難以快速掌握嚴重度分佈。

⚪ N/A

Bitbucket Signature 驗證

Bitbucket Cloud 本身不提供內建 Webhook Signature。架構上已預留 BitbucketSecretOptions 欄位，無需額外補齊。

4
今日變更摘要
新增 DiffHelper.cs + 修改 CodeReviewService.cs

三個方法集中在 Application/Utilities/DiffHelper.cs，Bitbucket / GitLab / GitHub 三平台共用， 解決 Linter 各自散落重複實作（且 GitHub 漏掉 RemoveDeletedLines）的問題。

方法 說明 對應 Linter
RemoveDeletedLines(diff) 移除 - 開頭的內容行，保留 --- header Bitbucket ✅ / GitLab ✅ / GitHub ❌（漏掉）
HasAddedLines(diff) 確認含 + 行（非 +++）才送 Dify Bitbucket ✅ / GitLab ❌ / GitHub 僅判空
IsAutoGeneratedContent(diff) 前 20 行偵測 <auto-generated> 三平台皆有但各自寫了一次
CodeReviewService.cs — per-file 三層 guard
// ❶ 無新增行 → skip（只有刪除不需要 AI） if (!DiffHelper.HasAddedLines(diffFile.Diff)) { _logger.LogInformation("[{TraceId}] File {File}: no added lines, skipped", ...); continue; } // ❷ Auto-generated → skip if (DiffHelper.IsAutoGeneratedContent(diffFile.Diff)) { _logger.LogInformation("[{TraceId}] File {File}: auto-generated content detected, skipped", ...); continue; } // ❸ 移除刪除行後送 Dify FileDiff = DiffHelper.RemoveDeletedLines(diffFile.Diff)
