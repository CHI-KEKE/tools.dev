Static-only 的意思是：
目前只能做「看程式、寫規格、設計案例」這類不執行 API 的工作。

不是指案例沒有用，而是目前還不能安全、正確地真的跑它們。


已經可以做
├─ 分析 Legacy 程式
├─ 分析 Target 設計
├─ 決定新 API Contract
├─ 設計 45 個測試案例
├─ 規劃每個案例需要的資料角色
└─ 檢查案例是否涵蓋所有行為

目前不能做
├─ 呼叫 Legacy 業務 API
├─ 呼叫 Target 業務 API
├─ 宣稱案例測試通過
├─ 建立 Golden Master
├─ 建立或修改測試資料
└─ 開始搬移正式程式碼



第一，Target 回應外殼還沒完全決定。例如究竟是：
{
  "Status": "Success",
  "ErrorId": ""
}
還是：
{
  "Status": "success"
}


第二，Runner 還不能真正製造部分測試情境。例如「缺少 Token」案例，Runner 現在反而會自動補上有效 Token；「過期 Timestamp」案例，Runner也會自動產生現在的時間。因此直接執行會測錯東西。
