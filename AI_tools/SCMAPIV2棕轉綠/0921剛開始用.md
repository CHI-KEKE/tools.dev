IIS Express 執行的不是 Git 裡的 .cs 原始碼本身，它主要載入網站 bin 裡已經編譯好的 DLL。
build 會做幾件重要的事：

  1. 編譯目前的 .cs 原始碼。
  2. 檢查程式碼是否能編譯。
  3. 檢查引用的 DLL 是否存在且相容。
  4. 產生網站實際執行的 DLL。
  5. 把需要的套件 DLL 複製到網站的 bin。
  6. 產生或更新必要的組態輸出。
