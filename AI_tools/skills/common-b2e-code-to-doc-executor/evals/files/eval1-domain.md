# 會員等級 Domain Document

## 1. 核心業務價值

會員等級系統用於激勵消費行為，依累積消費金額將會員分級，不同等級享有不同優惠折扣與服務。

## 2. MemberTier 等級定義

| 等級值 | 名稱 | 升等條件（年累積）|
|--------|------|-------------------|
| 0 | Normal | 預設 |
| 1 | Silver | 累積消費 ≥ 3,000 元 |
| 2 | Gold | 累積消費 ≥ 10,000 元 |

最高等級目前為 Gold（值為 2）。

## 3. 等級升降規則

- 每年 1 月 1 日統一重算等級
- 升等立即生效，降等延至下一年度
- 等級變更觸發 MemberTierChanged 事件，通知 CRM 系統

## 4. 外部整合

- CRM 訂閱 MemberTierChanged 事件後更新標籤
- EDM 系統依等級決定行銷信件模板
