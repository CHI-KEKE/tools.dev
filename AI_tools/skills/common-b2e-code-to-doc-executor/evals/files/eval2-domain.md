# 支付流程 Domain Document

## 1. 核心業務價值

支付模組負責處理會員的線上結帳交易，串接第三方支付閘道，確保金流安全與資料一致性。

## 2. 支付流程說明

使用者在結帳頁確認訂單後，系統進行以下流程：
1. 驗證支付資訊（卡號、金額、格式）
2. 呼叫支付閘道進行扣款
3. 儲存交易紀錄
4. 發送 PaymentCompleted 事件，通知訂單系統

若驗證失敗，拋出 InvalidPaymentException，結帳中止。

## 3. 業務規則

- 同一筆訂單不可重複扣款
- 支付閘道超時視為失敗，不重試
- 事件發送失敗不影響交易結果

## 4. 外部整合

- 訂單系統訂閱 PaymentCompleted 更新訂單狀態
- 財務系統每日對帳
