**Format Example:**
```markdown
-   `spacing-xs`: `4px`
-   `spacing-sm`: `8px`
-   `spacing-md`: `16px`
-   `spacing-lg`: `24px`
-   `spacing-xl`: `32px`
-   ...
```

**CSS Variables Format:**
```css
:root {
  --spacing-xs: 4px;
  --spacing-sm: 8px;
  --spacing-md: 16px;
  --spacing-lg: 24px;
  --spacing-xl: 32px;
}
```

**Tailwind Config Format:**
```javascript
spacing: {
  xs: '4px',
  sm: '8px',
  md: '16px',
  lg: '24px',
  xl: '32px',
}
```
