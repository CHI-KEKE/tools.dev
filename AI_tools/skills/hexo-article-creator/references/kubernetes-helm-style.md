# Kubernetes 藍白極簡風

來源：Allen 提供的 `C:\Dev\pics-cloudflare\style\k8s.png`。這是依該圖片歸納的視覺方向，不是官方品牌規範；不依賴來源檔案持續存在。可搭配 `assets/components/kubernetes-helm-style.html` 的可選元件。

## 圖片觀察

- 白色背景上方置中一枚藍色七邊形徽章，轉角略圓；內部是白色舵輪，圓環、輻條與中心留白形成清楚的負空間。
- 下方是大尺寸、厚重、小寫的深灰黑無襯線字標。圖形與文字上下排列，識別重心集中，周圍留白充足。
- 主要只有藍、白、深灰黑三色。扁平實色、清楚輪廓，沒有可見的漸層、材質紋理、玻璃效果、光暈或立體陰影。
- 圖片左右的字標裁切、右下角介面圖示不屬於設計語言，不複製到文章。圖片不足以判斷確切字型名稱。

## 轉成文章的設計規則

以下色票是目視近似與閱讀用途延伸，不是精確取色或官方色碼：

| 用途 | 色碼 | 套用方式 |
|:---|:---|:---|
| 主藍 | `#326de6` | 徽章、短線、少量重點色塊 |
| 純白 | `#ffffff` | 主背景、藍色塊上的大字或圖形 |
| 炭黑 | `#333333` | 標題與正文 |
| 深藍 | `#2455b5` | 白底連結、小字強調，屬閱讀延伸色 |
| 淡藍 | `#eef4ff` | 中性補充框，屬閱讀延伸色 |
| 灰藍 | `#d5deed` | 細邊框、表格分隔，屬閱讀延伸色 |

- 開場以白底粗黑標題配小面積藍色幾何徽章；不要因其他品牌元件有漸層 Hero 就照搬。大型字標的「厚重感」轉成標題字重，不照搬超大尺寸或裁切。
- 使用系統無襯線字體，標題 700–800 字重、正文正常字重；程式碼才用等寬字體。正文保持舒適行距，不將整篇做成 Logo 展示板。
- 七邊形只作少量裝飾；正式架構節點維持圖型原本的形狀與語意。圓環與放射結構可作視覺聯想，但不能因 Logo 有輻條就替系統捏造七個元件或七條連線。
- 使用細邊框、小圓角、寬鬆留白，少用卡片。比較使用表格，流程使用真正的流程圖或時間軸，服務互動使用時序圖。
- 品牌藍只表示主題或重點，不代表成功、健康或已部署。告警需要明確狀態文字；若另加紅／琥珀／綠，依共用規範表達危險／待觀察／已解決，不混作分類色。
- 適合 Kubernetes、容器編排、叢集管理、部署與雲端原生技術筆記。事故分析可借用中性排版，但狀態與風險語意優先。非相關主題不要直接加入 Kubernetes 識別圖案。
- 範本的七邊形是抽象裝飾，不是官方 Logo。若需正式 Logo，使用使用者提供的完整可用素材或另行查核的品牌資產，不用 emoji 或 CSS 仿畫舵輪替代並稱為官方圖示。
- 深色模式是為閱讀延伸的深藍灰底、淺色文字與亮藍重點，不是原圖觀察。保留平面風格，避免發光或漸層。

## 使用與驗證

先依 `SKILL.md` Step 1 確認文章風格與逐段呈現方案。本文件與範本提供素材，不要求每篇固定使用全部元件，也不授權修改或發布文章。

範本提供開場橫幅、章節標題、補充框、比較表及程式碼區塊。CSS 限定於 `.kubernetes-helm`，在文章定義一次；HTML 頂格書寫，`pre` 內不留空白行。補充框使用正常文流，避免行內 `code` 被 flex 拆散。比較表只在自身範圍橫向捲動，不對全站套用固定欄寬。

套用時依 `hexo-conventions.md` 與既有建置流程檢查桌面、手機及深色模式，尤其長標題、表格、程式碼右側空白與主題 CSS 覆蓋。範本本身不代表已在文章中驗證。
