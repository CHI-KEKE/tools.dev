## 環境設定範本（TranslationSetting）

所有環境的 `settings.*.json` 需在 `_N1CONFIG` 區段加入以下設定：

```json
"TranslationSetting": {
  "ServiceBaseUrl": "https://s3-ap-northeast-1.amazonaws.com/91dev-ap-northeast-1-translation-service/{ProjectName}",
  "S3RestApiBaseUrl": "https://91dev-ap-northeast-1-translation-service.s3.amazonaws.com",
  "OutputPath": "./Common/{ProjectName}.Common.Translations",
  "ProjectName": "{ProjectName}",
  "Namespace": "{ProjectName}.Common.Translations",
  "DefaultLocale": "zh-TW",
  "Locales": [
    "en-US", "ja-JP", "ms-MY", "th-TH", "zh-CN", "zh-HK", "zh-TW"
  ],
  "Modules": [
    "backend.service.discount_type"
  ]
}
```

> `DefaultLocale` 依環境調整：TW → `zh-TW`、HK → `zh-HK`、MY → `en-US`

## 新增翻譯模組的步驟

1. **在 `translation_config.json` 的 `Modules` 陣列加入新模組名稱**
   ```json
   "Modules": ["backend.service.discount_type", "your.new.module"]
   ```

2. **同步更新所有環境 `settings.*.json` 的 `TranslationSetting.Modules`**

3. **執行 Cake 任務重新生成**（本機）
   ```bash
   dotnet cake "./src/translation.cake" --Target="Init Translation"
   ```

4. **CI/CD 自動處理**：Pipeline 的 `unit:test:prepare` + `Dockerfile buildTranslation` 會自動執行初始化。

## CI/CD Pipeline 翻譯流程

### `unit:test:prepare` Job（`7821448` 新增）

```yaml
unit:test:prepare:
  image: "docker.build.91app.io/91app/dotnet-sdk-base:3.1"
  stage: prepare
  script:
    - 'dotnet new tool-manifest'
    - 'dotnet tool install Cake.Tool --version 2.0.0'
    - 'dotnet cake "./src/translation.cake" --Target="Init Translation"'
    - "mkdir ./i18n-resources"
    - "mv ./src/Common/{ProjectName}.Common.Translations/AutoGenerated i18n-resources/AutoGenerated"
    - "mv ./src/Common/{ProjectName}.Common.Translations/i18n i18n-resources/i18n"
  artifacts:
    paths:
      - i18n-resources
    expire_in: 1 day
  only:
    refs:
      - master
      - /^dev-\d{8}(-\d{4})?$/
      - /^feature.*/
```

### `unit-test` Job 調整（`10701bd`）

```yaml
# 在 dotnet test 之前複製翻譯資源
- 'cp -r ./i18n-resources ./src/Common/{ProjectName}.Common.Translations'
- 'dotnet restore ./src/{SolutionName}.sln'
- 'dotnet test --no-restore ./src/{SolutionName}.sln'
```

### `Dockerfile` 翻譯建置階段（`10701bd`）

```dockerfile
FROM docker.build.91app.io/91app/dotnet-sdk-base:3.1 as buildTranslation

WORKDIR /src
COPY ./src .
RUN dotnet new tool-manifest
RUN dotnet tool install Cake.Tool --version 2.3.0
RUN dotnet cake "./translation.cake" --Target="Sync Translation" --buildEnv="${DOTNET_BUILD_CONFIG}" --verbosity=diagnostic
RUN dotnet cake "./translation.cake" --Target="Init Translation" --buildEnv="${DOTNET_BUILD_CONFIG}" --verbosity=diagnostic
```

## Program.cs 翻譯服務註冊

```csharp
//// translation
builder.Services.AddTranslationsClient(settings =>
{
    settings.CacheDuration = 60;
    settings.ServiceBaseUri = new Uri(builder.Configuration["_N1CONFIG:TranslationSetting:ServiceBaseUrl"]!);
    settings.S3RestApiBaseUri = new Uri(builder.Configuration["_N1CONFIG:TranslationSetting:S3RestApiBaseUrl"]!);
    settings.ProjectName = builder.Configuration["_N1CONFIG:TranslationSetting:ProjectName"];
    var modules = builder.Configuration.GetSection("_N1CONFIG:TranslationSetting:Modules").Get<string[]>();
    settings.Modules = new HashSet<string>(modules);
    var fetchLocales = builder.Configuration.GetSection("_N1CONFIG:TranslationSetting:Locales").Get<string[]>();
    settings.FetchLocales = new HashSet<string>(fetchLocales);
    settings.StorageProviders = new List<IStorageProvider>()
    {
        new FileStorageProvider(AppDomain.CurrentDomain.BaseDirectory, "i18n",
            builder.Configuration["_N1CONFIG:TranslationSetting:ProjectName"])
    };
});

// Middleware 與初始化（app.Build() 之後）
app.UseMiddleware<TranslationsMiddleware>();
app.Services.RegisterTranslationsClient();
```

## TranslationsMiddleware 行為

語系判斷優先順序：

1. **Query String** `?lang=zh-tw` — 最優先
2. **Cookie** `lang=zh-tw` — 次優先
3. **Config 預設值** (`TranslationSetting:DefaultLocale`) — 兜底

僅接受 `TranslationSetting:Locales` 清單中的語系，不在清單內的一律 fallback 至預設值。

## 注意事項

- `AutoGenerated/` 與 `i18n/` 目錄已加入 `.gitignore`，不納入版控，由 Pipeline 動態生成。
- 本機開發若需要翻譯資源，需手動執行 `dotnet cake "./src/translation.cake" --Target="Init Translation"`。
- `translation.cake` 的 `Sync Translation` 任務只在 `buildEnv=Release` 時執行（Prod/PP 環境同步）。
- `Nine1.Translation.Client` 在 `Common.Translations` 專案用 `1.0.1`，在 Web API 主專案用 `1.1.0`，兩者版本不同，注意對齊。
