## Phase 8: AppSettings Configuration

Config 設定位於 **WebAPI 專案**（非 MobileWebMallV2），依各環境各市場各有獨立 config 檔：

```
WebStore/WebAPI/AppSettings.Debug.MY.config
WebStore/WebAPI/AppSettings.QA.MY.config
WebStore/WebAPI/AppSettings.Prod.MY.config
（以及其他市場：TW、SG、HK 等）
```

依 Step 1 確認的**收付模式**加到對應 key：

| 收付模式 | Key 名稱 |
|---|---|
| DirectToBank | `Dev.PayType.DirectToBank` |
| ThroughPSP | `Dev.PayType.ThroughPSP` |
| DirectToBankMid | `Dev.PayType.DirectToBankMid` |

範例：
```xml
<add key="Dev.PayType.DirectToBank" value="...,CreditCardOnce_Razer,PayNow_Razer,NewPayType_Razer" />
```

> 📌 目前 MY 環境的 `DirectToBank` 包含所有 Razer 系列（含 PayNow_Razer），新 Razer paytype 通常加此 key。

## Post-Translation: T4 Template (if available)

If the translation source is managed via T4 template:
1. Navigate to `WebStore/Translation/`
2. Add the translation key + value for all supported languages to the source (`.resx` or database)
3. Run the T4 template: right-click `generate.tt` → **Run Custom Tool**, or via CLI:
   ```powershell
   cd WebStore\Translation
   TextTransform.exe generate.tt
   ```
4. Verify `generate.txt` output shows the new files were updated without errors

Supported languages typically include: `zh-TW`, `en-US`, `zh-CN`, `ja-JP`, `ms-MY`
