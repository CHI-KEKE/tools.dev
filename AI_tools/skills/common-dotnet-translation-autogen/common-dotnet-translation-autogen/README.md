# common-dotnet-translation-autogen

當 .NET 專案因多語系 AutoGenerated 檔案遺失導致建置失敗時，自動執行 `translation.cake` 重新產生翻譯類別並重新建置。

## 用途

`.NET` 專案（Nine1.Live.Buy 等）的 AutoGenerated 翻譯 C# 檔案**不進版本控制**。  
每次環境重建後必須重跑產生流程，否則 `dotnet build` 會出現大量 `CS0117` 錯誤。

此 Skill 負責自動偵測這類失敗、執行 Cake script 重新產生檔案，並重跑建置。

## 觸發情境

| 使用者說 | 觸發 |
|---|---|
| `dotnet build` 出現多個 `CS0117 'ClassName' does not contain a definition for 'SomePascalCaseMember'` | ✅ |
| 「AutoGenerated 資料夾是空的」、「翻譯類別不見了」 | ✅ |
| 「多語系」、「語系」、「翻譯」、「translation」 | ✅ |
| 「build 之前都正常，現在一堆 missing member 錯誤都指向同幾個 class」 | ✅ |

> **判斷依據**：多個 CS0117 錯誤指向**同一個 class**，且該 class 位於 `Common.Translations` 命名空間或 `AutoGenerated/` 目錄下。

## 執行流程

```
Step 1：確認是翻譯相關失敗（CS0117 多個指向同一 class，在 Translations 命名空間下）
Step 2：定位 translation.cake（從 repo root 遞迴搜尋）
Step 3：還原 dotnet tools（dotnet tool restore，從 repo root 執行）
Step 4：執行 dotnet-cake translation.cake --target="Init Translation"
Step 5：重新執行 dotnet build --no-incremental
Step 6：回報執行摘要
```

## Init Translation 執行內容

| Task | 說明 |
|---|---|
| `Install Translation-AutoGen-Tool` | 從私有 NuGet Feed 安裝 `nine1.translations.client.tools.autogen` |
| `Fetch Modules` | 呼叫 Translation API 更新 `translation_config.json`（失敗時保留現有清單，繼續執行） |
| `Auto Gen modules` | 從 S3 下載翻譯資料，寫入 `AutoGenerated/*.cs` 原始碼檔案 |

## 前置條件

| 條件 | 說明 |
|---|---|
| `.config/dotnet-tools.json` | 位於 repo root，需已宣告 `cake.tool` |
| **私有 NuGet Feed 憑證** | 安裝 AutoGen Tool 需存取 Nexus（見下方說明） |
| Translation Service 網路連線 | 用於 Fetch Modules；失敗時可繼續，但 module 清單不會更新 |
| S3 網路連線 | 用於下載翻譯資料並產生 AutoGenerated/*.cs；若無法連線則 AutoGen 失敗 |

### 私有 NuGet Feed 憑證設定

`Install Translation-AutoGen-Tool` 步驟從以下私有 Nexus Feed 安裝工具：

```
https://entry.build.91app.io/repository/nineyi-release-nuget-hosted/
```

**初次設定（一次性）：**

使用 91APP Nexus 帳號（與 Jenkins/Sonar 相同的 LDAP 帳號），執行：

```powershell
dotnet nuget add source https://entry.build.91app.io/repository/nineyi-release-nuget-hosted/ `
  --name "Nine1.Nuget.Release" `
  --username <your_username> `
  --password <your_password> `
  --store-password-in-clear-text
```

或透過 Visual Studio 設定：

1. **Tools → NuGet Package Manager → Package Sources**
2. 新增來源：URL 填入上方網址
3. 點擊齒輪圖示 → 輸入帳號密碼

> 憑證儲存後，後續建置不需重複輸入。若出現 `401 Unauthorized` 錯誤，表示密碼已變更，需重新執行上述指令。

## 常見殘留錯誤診斷

| 錯誤模式 | 可能原因 |
|---|---|
| CS0117 仍指向**同一個**翻譯 class | `Auto Gen modules` 執行成功但無法從 S3 取得資料（確認網路或 Translation Service 狀態） |
| CS0246 `type … not found` | 缺少 NuGet 套件或新的實體類別尚未建立，非翻譯問題 |
| CS0117 指向**不同**的 class（非翻譯相關） | NuGet 套件缺少新的 enum 值，需更新套件 |

## 適用專案類型

此 Skill 僅適用於 **.NET（非 .NET Framework）** 的專案，使用 `translation.cake` 作為產生工具。

> ⚠️ .NET Framework 專案使用 T4 範本（`generate.tt`），產生流程不同，請參考 `common-translation-workflow` Skill。

## 維護說明

更新時機：
- `translation.cake` 的 target 名稱異動
- AutoGen tool 的 NuGet 套件名稱變更
- S3 endpoint 或 Translation Service API 有異動
- 新增診斷規則（新的 CS0117 變體或其他翻譯相關錯誤樣式）
