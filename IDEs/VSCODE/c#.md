
# VS Code C# 偵錯快速筆記

## 需要先安裝的延伸套件

- `C# Dev Kit`

## 如何開始偵錯

1. 打開要偵錯的 `.cs` 檔案。
2. 在目標程式碼行號左側點一下，加入 breakpoint。
3. 按 `F5` 開始偵錯。
4. 程式停在 breakpoint 後，就可以用下列快捷鍵逐步查看流程。

## 常用偵錯快捷鍵

| 快捷鍵 | 功能 | 說明 |
| --- | --- | --- |
| `F10` | Step Over | 一行一行往下執行，但不進入方法內部 |
| `F11` | Step Into | 進入目前這一行呼叫的方法內部 |
| `Shift + F11` | Step Out | 從目前方法跳出，回到上一層呼叫位置 |
| `F5` | Continue | 繼續執行，到下一個 breakpoint 或程式結束 |
| `Shift + F5` | Stop | 停止偵錯 |

## 偵錯畫面常看的區塊

- `Variables`：查看目前變數的值。
- `Watch`：手動加入想持續觀察的變數或表達式。
- `Call Stack`：查看目前的呼叫堆疊，了解程式怎麼走到這裡。
- `Debug Console`：查看輸出內容，必要時也能互動或輸入指令。

## 最常用的操作流程

如果只是想快速查問題，通常照下面做就夠了：

1. 設 breakpoint。
2. 按 `F5` 開始。
3. 用 `F10` 一步一步往下看。
4. 想進方法裡面時按 `F11`。
5. 看 `Variables` 與 `Watch` 判斷值是否正確。
6. 看完後按 `Shift + F5` 結束偵錯。
