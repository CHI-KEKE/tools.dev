標籤頁
標籤頁文件名不一定是 tags, 例子中的 tags 只是一個示例
記得添加 type: "tags"

前往你的 Hexo 的根目錄

輸入 hexo new page tags

你會找到 source/tags/index.md 這個文件

修改這個文件：

---
title: 標籤
date: 2018-01-05 00:00:00
type: 'tags'
orderby: random
order: 1
---
參數	解釋
type	【必須】頁面類型，必須為 tags
orderby	【可選】排序方式 ：
random - 隨機排序 / name - 標簽名字排序 / length - 標簽數量排序
order	【可選】排序次序： 1（升序），-1（降序）
