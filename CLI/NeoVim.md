
## 確認環境


1. PowerShel 執行 refreshenv
2. 確認安裝成功 nvim --version





## 編輯 JSON 檔

1. 開啟檔案

nvim "C:\Users\Allen Lin\.copilot\mcp-config.json"


2. 進入編輯模式

- 啟後預設是「一般模式」，不能直接打字
- i 進入編輯模式（左下角會出現 -- INSERT --）
- 在就可以用方向鍵移動、編輯內容了


## 編輯內容

- 用方向鍵移動游標到要修改的地方
- 直接打字修改


## 存檔離開

- 按 Esc 退出編輯模式（回到一般模式）
- 輸入 :wq 然後按 Enter → 存檔並離開


## 常用緊急指令

┌──────┬────────────────────────────────┐
│ 指令 │ 動作                           │
├──────┼────────────────────────────────┤
│ i    │ 進入編輯模式                   │
├──────┼────────────────────────────────┤
│ Esc  │ 回到一般模式                   │
├──────┼────────────────────────────────┤
│ :wq  │ 存檔離開                       │
├──────┼────────────────────────────────┤
│ :q!  │ 不存檔強制離開（改壞了用這個） │
└──────┴────────────────────────────────┘
