## 為甚麼我的wsl不是ubuntu?


wsl --list --verbose


  NAME              STATE           VERSION
* docker-desktop    Running         2
  Ubuntu            Stopped         2

  * 代表目前的 Default Distribution。
所以如果是：
* docker-desktop

那你直接執行：
wsl

WSL 就會把你送進 docker-desktop，自然不會進 Ubuntu。



如果 Ubuntu 已經存在
假設 wsl -l -v 有：
Ubuntu

直接指定它：
wsl -d Ubuntu

確認可以正常進去之後，再把 Ubuntu 設為預設：
wsl --set-default Ubuntu


## user

adduser yoyo

再把它加入可以 sudo 的群組：
usermod -aG sudo yoyo


切換
su - yoyo


sudo whoami
輸入剛才設定的密碼後，如果輸出：
root

代表 sudo 正常。


## 設定 WSL 預設使用者

wsl
nano /etc/wsl.conf
加入

[user]
default=yoyo


存檔：Ctrl + O → Enter → Ctrl + X

exit

## Docker Desktop 還沒有把 Docker CLI / Engine 整合給這個 Ubuntu distro。


Docker Desktop 本來就支援把 Docker 能力提供給 WSL distro，所以不用另外在 Ubuntu 裡安裝一套 Docker Engine。

到 Docker Desktop 開啟 WSL Integration
打開 Windows 的 Docker Desktop：
Settings → Resources → WSL Integration
